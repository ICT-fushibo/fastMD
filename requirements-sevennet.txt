# The optional SevenNet model family (fastmd.adapters.sevennet): sevenn 0.13.0 (SevenNet-0 ships inside its
# wheel) and cuEquivariance 0.9.1 for CUDA 13, plus the dependencies of sevenn that a PyTorch environment lacks.
# Exact versions, each with the sha256 of its PyPI file.
#
# Platforms: the platform wheels are the Linux aarch64 ones (Grace CPUs, e.g. GB200) for CPython 3.12: matscipy,
# scikit-learn and cuequivariance-ops-torch-cu13 (cp312), and cuequivariance-ops-cu13 (any Python 3). The others
# are pure Python. An x86_64 environment needs its own hashes for those four files (PyPI has x86_64 wheels of all
# four; a requirement may list several --hash options).
#
# Install over an environment that already runs fastmd, in a virtual environment that sees its packages:
#
#   python -m venv --system-site-packages <venv>
#   <venv>/bin/python -m pip install --no-deps --require-hashes -r requirements-sevennet.txt
#
# These pins come from MD's tools/ci/sevennet_lane.sh; that script is not shipped with FastMD.
# Normal installation uses pyproject.toml: python -m pip install -e '.[gpu-graph,sevennet]'.
# See README.md for the optional CUDA 13 acceleration extra and the platform limits of this file.
#
# Deliberately not installed, the base environment provides them: torch, numpy, scipy, ase, nvalchemi-toolkit-ops,
# warp-lang and triton (the versions fastmd runs with stay in place), and nvidia-cublas, a dependency of
# cuequivariance-ops-cu13 (the base environment's CUDA 13 cuBLAS is used). The base environment also provides the
# other dependencies of these packages: pandas, PyYAML, tqdm, requests, ninja, setuptools, joblib, and
# torch_geometric's aiohttp, fsspec, Jinja2, psutil, pyparsing and xxhash.
#
