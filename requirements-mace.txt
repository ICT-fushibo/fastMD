# The optional MACE model family (fastmd.adapters.mace): mace-torch 0.3.16 and cuEquivariance 0.9.1 for CUDA 13,
# plus the dependencies of mace-torch that a PyTorch environment lacks. Exact versions, each with the sha256 of its
# PyPI file.
#
# Platforms: the platform wheels are the Linux aarch64 ones (Grace CPUs, e.g. GB200) for CPython 3.12: matscipy,
# h5py, lmdb and cuequivariance-ops-torch-cu13 (cp312), and cuequivariance-ops-cu13 (any Python 3). The others are
# pure Python. An x86_64 environment needs its own hashes for those five files (PyPI has x86_64 wheels of all
# five; a requirement may list several --hash options).
#
# Install over an environment that already runs fastmd, in a virtual environment that sees its packages:
#
#   python -m venv --system-site-packages <venv>
#   <venv>/bin/python -m pip install --no-deps --require-hashes -r requirements-mace.txt
#
# These pins come from MD's tools/ci/mace_lane.sh; that script is not shipped with FastMD.
# Normal installation uses pyproject.toml: python -m pip install -e '.[gpu-graph,mace]'.
# See README.md for the optional CUDA 13 acceleration extra and the platform limits of this file.
#
# Deliberately not installed, the base environment provides them: torch, numpy, ase, nvalchemi-toolkit-ops,
# warp-lang and triton (the versions fastmd runs with stay in place), and nvidia-cublas, a dependency of
# cuequivariance-ops-cu13 (the base environment's CUDA 13 cuBLAS is used). The base environment also provides the
# other dependencies of these packages: scipy, sympy, networkx, packaging, wcwidth, tqdm, platformdirs,
# nvidia-ml-py, and mace-torch's torchmetrics, python-hostlist, GitPython, PyYAML, orjson, matplotlib and pandas
# (matscipy 1.3.0 declares ase >= 3.27 and numpy >= 2).
#
